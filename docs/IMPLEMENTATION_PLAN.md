## 有限收尾與可選研究

本機 Mock/Replay 交付須完成乾淨環境啟動、十步示範及精確新版本隱私／發布審查。一般 gateway UI 啟動仍未實作；不得繞過私人 runner。額外付費研究、Multi 勝出或 Critic 因果效益都不是此交付的前提。

下列研究只在另有明確授權時進行，不代表已排程或尚缺既有 Owner 設定：

1. 凍結當次模型、價格、總預算及伺服器端 transport policy，保存 provider 輸出與費用證據；實際完成狀態依私人 receipts，不能由此通用文件推斷。
2. 固定模型、prompt、資料雜湊與成本預算，以 2019–2023 開發期及 2024 驗證期執行單／多 Agent 實驗，保存失敗、跳過、token、延遲與費用。
3. 凍結設定後再執行 2025 保留期間；不得使用 Mock 結果回答模型績效研究問題。
4. 補足含股息敏感度分析、研究結果與學習反思；這些不是目前 price-only 軟體功能測試的成果。
