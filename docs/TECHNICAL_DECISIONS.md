2026-10-24：以下補足 v0.1 藍圖中的實作歧義；保留 SPY、日線、週決策、下一開盤、四組比較與研究用途。

1. **報酬與資料**：MVP 僅使用 raw OHLC 的 price-only return，股息／利息為零，不自動期末平倉；結果標示此限制。以明確標示的合成行情提供可再散布的離線 Demo。個人研究的真實 SPY CSV 存 `data/cache/`，由顯式下載／匯入建立；不得將 Yahoo 行情當作可隨程式任意再散布的資產。實際下載仍須遵守來源使用條款。調整價資料不接受 raw 標籤。
2. **時間契約**：XNYS 日曆定義每週最後交易日與下一交易日；資料在首末日期間缺任何正常 session 即拒絕。所有策略從範圍內第一個暖機完成的週末收盤決策、下一開盤進場；Buy & Hold 只首次配置。期末無可成交 session 的訊號記錄跳過。按每日收盤估值。
3. **特徵**：MA20/60 需完整視窗；RSI14 以首 14 個變動的平均漲跌為 Wilder 種子，完全平盤為 50；ATR14 以首 14 個 TR（首日 high-low）作種子；日對數報酬標準差採 ddof=1、20 筆、√252。修改未來行情不影響過去數值特徵；整份資料雜湊與衍生 ID 隨資料版本改變是預期的 provenance 差異。
4. **成交與帳本**：用下一開盤估值計算目標權重，數量同時解出費用與方向性滑價造成的權益減少，使成交後按未滑價開盤估值的權重符合目標。容許小數股；僅以極小浮點誤差容忍，不能用負現金融資。滑價已包含在成交價格，帳本不再額外扣一次。
5. **績效**：報酬以初始現金為基準；每日報酬首值也以初始現金計算。CAGR 與 Sharpe 年化均採 252/n 交易日；最大回撤含初始資產值、使用負比例。零波動 Sharpe 與零回撤 Calmar 回傳 null。換手率為絕對成交額／平均每日權益。成本、曝險比例、成功與跳過決策數一起揭露。
6. **Agent 邊界**：Agent 僅收數值特徵及前序驗證後輸出；日期、標的、帳戶與未來行情不送入模型。風控與帳本的入口不在 Agent 工具中。schema 拒絕額外欄位、非有限數與無效 evidence。失敗保留原持倉，零目標代表主動平倉。
7. **Trace / Replay**：每筆決策內嵌不可變 snapshot、模型輸入、原始輸出、schema／prompt／input hash、驗證結果、用量、成本、風控與成交參照。Replay 指向原 run，核對資料雜湊、策略、feature/prompt version 與 input hash；不重新呼叫模型。Replay 重跑當前風控／帳本，另記引擎版本，與原始結果可比較。
8. **工作者**：單一程序、單一序列 worker；SQLite WAL、明確交易與不可變完成結果。以程序級排他鎖避免兩個服務同時管理同一資料庫；啟動將遺留 PENDING/RUNNING 標記 FAILED。長任務不佔 HTTP 請求；建立回傳 202 與 run_id。
9. **提供者**：Mock 與 Replay 必須離線可用。API 提供者只由後端環境變數配置，未配置時明確不可用；開發測試不自動花費付費模型額度。Mock 的策略行為與 token/成本不得包裝成真實 LLM 研究成果。
10. **版本**：Python 3.13，Node 22.17.1；直接依賴以 2026-10-24 PyPI/npm registry 核對的版本固定，完整傳遞依賴由 uv.lock / package-lock.json 保存。安裝、型別檢查與實際測試通過後記錄驗收。
11. **研究解讀**：2025 僅為本專案開發的保留期間，不宣稱模型未接觸過的資料。四組同資料、期間、帳本與費率；成本公平性與決策成功率並列。獲利不是軟體完成條件。

12. **中斷保存與 SQLite**：請求前保存呼叫輸入與費用預留，回應後更新原始結果；run 失敗也可匯出事件紀錄。保留一個無交易的連線讓 WAL 持續開啟，避免每筆事件關閉最後連線觸發 checkpoint；所有活動資料庫交易由同一 Store 的執行緒鎖序列化。當前 Python 3.13.9 所帶 SQLite 3.50.4 尚在官方 WAL-reset bug 版本範圍內，此設計消除兩個連線同時寫入／checkpoint 的觸發條件。參考 [SQLite WAL 官方文件](https://sqlite.org/wal.html)。資料庫由單一平台程序管理。
