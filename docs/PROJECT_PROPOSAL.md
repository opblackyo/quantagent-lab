# 自發學習計畫書

## 一、計畫名稱

**基於多代理人工智慧之量化交易決策、風險管理與可視化研究平台設計與實作**

英文名稱：Design and Implementation of a Multi-Agent AI Quantitative Trading Research Platform

## 二、學習動機

隨著人工智慧與大型語言模型技術快速發展，AI Agent 已逐漸從單純的問答工具，轉變為能夠使用工具、分析資料、執行工作流程及協同完成任務的智慧系統。在金融科技領域中，量化交易涉及市場資料處理、技術分析、交易策略、風險管理與績效評估等多項工作，具有將不同職責拆分為多代理協作系統的研究價值。

過去在程式設計與系統開發的學習過程中，我逐步累積了軟體開發與應用系統實作的經驗，也對程式交易及量化分析產生興趣。然而，交易決策並非僅依靠單一指標或模型預測即可完成，還必須考慮風險限制、資料正確性、交易成本，以及決策結果是否能夠被解釋與驗證。

因此，本次自發學習計畫希望結合 Python、量化交易、LLM Agent、多代理協作與 Web 可視化技術，設計並實作一套研究平台。透過不同 Agent 分別提出市場觀點、檢查決策風險與整合交易建議，再使用程式化風控及歷史回測進行驗證，探索多代理人工智慧在量化交易研究中的實際應用價值，同時提升自己在人工智慧系統整合、金融資料分析及全端開發方面的能力。

## 三、學習目標

本計畫設定以下六項學習目標：

1. **理解量化交易研究流程**：學習市場資料取得、清理、技術指標、交易訊號、倉位管理及歷史回測。
2. **掌握多代理 AI 系統設計**：研究 LLM Agent 的角色分工、結構化輸入輸出、工作流程編排及異常處理。
3. **建立可驗證的交易風險管理機制**：以程式執行倉位限制、交易成本計算及交易合法性檢查，避免僅依賴語言模型判斷。
4. **開發完整可視化研究平台**：使用 Web 技術呈現市場行情、技術指標、Agent 決策流程、交易紀錄及回測績效。
5. **進行公平的策略比較實驗**：比較 Buy & Hold、傳統規則策略、單代理 AI 與多代理 AI 的研究結果。
6. **培養可重現的軟體研究能力**：建立測試、實驗設定、決策紀錄、版本管理及成果文件，使研究結果能夠重現與檢查。

## 四、執行方式

本計畫採取文獻研究、技術實作、系統整合及實驗驗證並行的方式進行。

首先，蒐集並閱讀量化交易、多代理人工智慧、LLM Agent、金融風險管理與歷史回測相關資料，並參考 TradingAgents、AI Hedge Fund 等開源專案，分析其角色分工、資料流程及技術架構。研究過程中將整理不同方案的優缺點，確立適合本計畫的系統範圍與實作方法。

其次，使用 Python 建立市場資料處理與量化研究核心。第一階段以美國股票市場 ETF 的日線資料為主要研究對象，計算移動平均線、相對強弱指標、平均真實波幅及波動率等特徵，並實作基本交易策略、風險限制與歷史回測。回測過程將明確區分決策時間與成交時間，納入手續費及滑價假設，以降低不合理回測結果的風險。

接著，設計多代理 AI 決策流程，由市場分析 Agent 提出市場觀點、批判 Agent 檢查推論與風險、決策 Agent 整合意見並輸出結構化交易建議。所有 AI 輸出都必須經過格式驗證及獨立風控程式審核，不直接連接真實券商下單。

在介面開發方面，使用 Next.js 與 Python FastAPI 建立前後端系統，整合 K 線圖、技術指標、Agent 決策歷程、交易紀錄、資產曲線與策略績效比較，讓使用者能夠操作平台並追溯每次決策的原因。

最後，使用相同市場資料、交易成本與回測規則，比較不同策略的報酬、最大回撤、Sharpe Ratio、交易次數與 AI 使用成本。整理研究結果、系統截圖、程式碼、測試紀錄及操作影片，並分析多代理架構的優點、限制與未來改善方向。

## 六、預期學習成效

完成本計畫後，預期能具備建立 AI Agent 量化研究系統的基礎能力，理解多代理協作、金融時間序列處理、風險管理、歷史回測及全端系統整合的實務方法。

具體成果包括一套具有操作介面的 Web 研究平台，可顯示市場資料與技術指標、執行單代理及多代理分析、呈現交易建議與風控結果、保存決策歷程，並比較不同策略的歷史績效。此外，將完成可重現的實驗紀錄、程式測試、系統架構文件及研究心得。

本計畫不以保證獲利或實際交易為目標，而是透過客觀實驗探討多代理人工智慧在交易決策中的應用價值。即使研究結果未顯示多代理策略優於傳統方法，仍可藉由分析決策品質、風險控制、成本與限制，獲得具有學習意義的成果。

## 八、研究範圍與限制

本計畫以研究及教育用途為主，僅進行歷史回測及模擬交易，不串接真實券商、不進行自動實盤下單，也不提供保證獲利的投資建議。

研究將以少量標的、日線資料與固定交易頻率為起點，避免因同時處理大量市場、即時行情與複雜策略而影響核心功能的完成品質。研究結果將受到資料品質、回測期間、模型成本與歷史樣本數量限制，並在成果報告中如實說明。

本計畫使用的開源程式庫與第三方技術將依其授權條款標註來源；自行設計的整合流程、風控規則、實驗方法、介面及測試內容，則作為主要實作與學習成果。
