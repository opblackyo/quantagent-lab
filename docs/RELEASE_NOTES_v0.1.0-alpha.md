# v0.1.0-alpha — draft release notes

QuantAgent Lab is a local multi-agent quantitative research workstation with inspectable decisions, deterministic risk controls, next-open historical simulation and interactive charts.

## Included

- Six connected research views and four strategy pipelines.
- Fixed Analysis → Critic → Decision workflow, schema validation and explicit risk boundary.
- No-key synthetic Mock demo and provider-free Replay.
- Cost-aware ledger, equity/drawdown, comparison, trace and JSON exports.
- Durable interrupted-call evidence, locked dependencies and automated local tests.

## Limitations

- Mock agents are fixed rules; their returns are not LLM research findings.
- The optional OpenAI adapter is fixture-tested; no paid-model study is included.
- Single-symbol daily data; price-only returns exclude dividends/interest.
- Local-only service, no authentication, no public hosting and no broker orders.

Release status: draft, unpublished. MIT is selected. Sanitized publication history, repository destination, hosted CI and final owner approval remain release gates. Do not attach private databases, real data caches, scanner reports or raw provider responses.
